# ADR 0002: 零焊接 bring-up 路線

**Status**: Validated 2026-04-26（零焊接路線採購驗證成功 — chip 排針已焊，杜邦線 + 麵包板插即用）
**Date**: 2026-04-26

## Context

Owner 硬體背景盤點：

- 從未焊接過任何元件
- 沒有焊接工具（烙鐵、錫絲、助焊劑、海綿座）
- 沒有 SMD 焊接經驗

本專案對 owner 同時是「**四個第一次**」：

1. 第一次玩 ESP32 firmware
2. 第一次寫 BLE GATT
3. 第一次焊接 / 接線
4. 第一次 3D 列印（OpenSCAD）

每個第一次都會卡住一次半天。同時並行 = 挫敗風險指數成長，可能直接放棄專案。

## Options Considered

| 路線 | 做法 | 風險 | 適合 |
|---|---|---|---|
| A. 入門焊接套件 + 自學 | 買 NT$300–600 烙鐵套件，邊做邊學 | 高 — 挫敗點 +1 | 想長期投入硬體 |
| **B. 完全避開焊接** | 採購已預焊版本所有元件，杜邦線插麵包板 | 低 | side project，先 bring-up |
| C. 找代焊 | 露天 / 蝦皮 / 金華現場代焊 | 低，但要 case-by-case | 採購量小、單一 SKU |

## Decision

bring-up 階段採用 **B + C 混合路線**：

1. **預焊版優先**：採購 ESP32 / Ring 都選「排針已焊」/「預焊接線」版本
2. **預焊版找不到**：找賣家代焊或金華實體店現場代焊（觀察到的 ESP32-C3 SuperMini 多數附排針未焊版本，需特別篩選或代焊）
3. **不買烙鐵 / 不自己焊** — 把這個變因從 bring-up 階段排除

## Rationale

1. **降低變因，先讓 firmware bring-up 跑通**
   - bring-up 階段如果出問題，要先排除「接觸不良 / 冷焊」這類硬體疑點
   - 零焊接 = 用麵包板 + 杜邦線連接，連接可靠性穩定
   - debug 時可聚焦在 firmware / GATT 邏輯，不用同時懷疑硬體
2. **保留興趣** — side project 不能讓「第一次玩硬體」變成「卡在烙鐵買哪支」。先讓 LED 亮起來、BLE 通了，再考慮要不要長期投入硬體技能
3. **未來可選升級** — 如果 firmware bring-up 跑通、外殼也想包緊（不能用麵包板），到時再學焊接，那時候動機強、目標明確（「我要把這條杜邦線焊死」），學習效率高

##採購清單（零焊接版）

| 物件 | 規格 / 注意點 | 約價 NT$ |
|---|---|---|
| ESP32-C3 SuperMini（**已焊排針版**） | ⚠️ 多數賣家不附排針，下單前確認「已焊」/「預焊」；找不到則改線上代焊或進金華實體店請店員代焊 | 150–220 |
| WS2812B 8 LED Ring（**預焊杜邦線版**） | 見 ADR 0001 | 80–150 |
| 麵包板 400 孔 | 入門款 | 30–50 |
| 杜邦線 公對母 + 母對母 各一包 | 接線通用 | 50–80 |
| USB-C 線 | ESP32 燒錄 + 供電（家裡可能已有） | 0 |

**估算總計**：NT$ 310–500

## Consequences

### 正面

- 採購清單可完全買到回家組裝
- 麵包板 + 杜邦線可隨時改接線、實驗
- bring-up 階段 debug 時硬體可靠性穩定

### 負面

- bring-up 階段體積大（麵包板 + ESP32 + Ring + 一堆杜邦線散在桌上），不適合「成品」
- 杜邦線 / 麵包板接觸不如焊接穩定，長期使用可能出現偶發接觸問題（bring-up 階段不影響）
- 3D 外殼設計受影響：若最終仍不焊，外殼要做成「容納整個麵包板組裝」的盒子；若改為焊接成品，外殼可緊湊很多 — **本 ADR 不處理這個決定，待 bring-up 完成後另開 ADR**

### 後續動作

- [x] 進金華**前**先打電話：今華電子 2026-04-26 確認沒代焊服務、建議現場看
- [x] 採購清單依此 ADR + ADR 0001 收齊（部分 — Ring 走蝦皮，麵包板等 M4b 再買）
- [ ] bring-up 完成後重新評估：是否要學焊接做永久成品
- [ ] 外殼設計（OpenSCAD）暫緩，等 bring-up + 焊接決議後再開 ADR

## Update 2026-04-26 — Procurement

零焊接路線**驗證成功**。Chip 從計畫的 C3 SuperMini 替換成 **ESP32-S3-WROOM-1 N16R8**（金華電子當下在貨的焊好版是 S3，de facto 紀錄見 [dev_setup.md → "Why ESP32-S3 (de facto)"](../dev_setup.md)）。

**對本 ADR 的「不焊」標準影響：零** — S3 / C3 都符合排針已焊 + Native USB-C 兩條件。

實際採購 vs 原 BOM 對照：

| 項目 | 原計畫 | 實採 (2026-04-26) |
|---|---|---|
| ESP32 dev board | C3 SuperMini NT$150–220 | **S3-WROOM-1 N16R8 NT$400**（金華電子，已焊排針） |
| WS2812B 8 LED Ring | 實體店預焊版 | **改走蝦皮**（見 ADR 0001 update），2-3 天到貨 |
| 麵包板 400 孔 | 入門款 | ⏳ 未採購（M4a 用板載 LED 不需要，待 Ring 到貨補） |
| 杜邦線 | 公對母 + 母對母 各一包 | 公對公 + 母對公 各一包（spec 略不同，M4b 接線時若不夠再補 母對母） |
| USB-C 線 | 既有 | 既有 |

**Lesson learned**：實體店預焊版「規格找不到 → 跑網購」是常態，不必硬等實體店。但實體店的價值在於 chip / dev board 的「現場挑選 + 看實物」，這個無法被網購取代。混合策略最務實。
